# DailyFurnace — «Печь дня» (Android)

Учебное Android-приложение для студентов-металлургов: лента технологических фактов и справочная информация о печах с экраном деталей, избранным и офлайн-доступом.
## ✨ Возможности
- Ежедневные уведомления о технологических фактах (**Firebase Cloud Messaging**).
- Экран ленты и экран деталей.
- Добавление в **избранное** и хранение данных локально.
- **Офлайн-доступ** к сохранённым данным.
- Навигация между **Fragment**-экранами.
- Сохранение состояния и пользовательских настроек.

## 🧱 Архитектура и подход
- **MVVM**
- Разделение ответственности по слоям (UI / Domain / Data)
- Состояния экранов: loading / content / empty / error

## 🛠️ Технологический стек
- **Kotlin**
- **MVVM**
- **Fragments**
- **View System:** XML, RecyclerView
- **Room** (локальная БД, избранное)
- **SharedPreferences** (настройки/состояние)
- **Firebase (FCM)** (уведомления)
- **DI:** Koin

## ▶️ Запуск проекта
1. Откройте проект в Android Studio и выполните Sync Gradle.
2. Для FCM добавьте `google-services.json` в модуль `app/` *(если он не закоммичен)* и убедитесь, что подключён плагин Google Services.
3. Запустите приложение на эмуляторе/устройстве.
